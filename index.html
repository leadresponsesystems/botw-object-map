About this map

A touch-first viewer for MrCheeze's Breath of the Wild object database. Tap a category, search by display name or internal ID, then show its locations. Drag and pinch the map normally.

Only visible markers are drawn, with a safety cap to avoid locking up mobile Safari. Zoom in to separate dense objects. Selected categories are saved on this device.

The main dataset is a large original file and must be downloaded once. The map image uses a smaller image service with a fallback to the original. Internet is required for object data. Independent viewer, not an official Nintendo or MrCheeze release.
